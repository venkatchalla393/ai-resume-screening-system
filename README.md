# AI Resume Screening System

An AI-powered Resume Screening System built using Python, Flask, and NLP techniques to analyze resumes and compare them with job descriptions.

---

## Features

* Resume PDF Upload
* Resume Text Extraction
* Dynamic Job Description Input
* AI-based Resume Matching
* Skill Extraction
* Match Percentage Calculation
* Modern Responsive UI
* Animated Result Dashboard
* Error Handling for Invalid PDFs

---

---

## Project Workflow

1. User uploads resume PDF
2. System extracts text from PDF
3. User enters job description
4. Resume and job description are converted into vectors using TF-IDF
5. Cosine similarity calculates matching score
6. System displays:

   * Resume Match Percentage
   * Detected Skills
   * Extracted Resume Text
